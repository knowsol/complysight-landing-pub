핵심은 자동화입니다.

하나의 프로세스로 통합합니다.

컴플리사이트는 점검 기준 입력부터 결과 보고까지,
흩어진 점검 정보를 하나의 프로세스로 통합합니다.

INPUT 입력 데이터

점검 기준 · 시스템 정보

  • 시스템 구성 정보자산 대장·네트워크 구조
  • 서버·DB·WAS 설정값실시간 수집 대상
  • 점검 기준행정안전부·기관 고유
  • 운영 환경 정보보안 정책·권한 구조

PROCESS 처리 로직

자동화된 점검 엔진

  • 기준 기반 비교사전 정의된 기준과 자동 대조
  • 항목별 자동 판별정상 주의 위험 상태 자동 분류
  • 결과 통합시스템 담당자 단위로 결과 집계
  • 예외 검토 플래그판단 필요 항목만 담당자에게 전달

OUTPUT 결과물

신뢰 가능한 산출물

  • 점검 결과 리포트표준 양식 · 자동 생성
  • 항목별 증빙원천 데이터 포함
  • 이력 로그타임스탬프 기록
  • 관리 대시보드실시간 현황 집계

점검보고, 보고확인
보고자와 관리자 모두 하나의 시스템으로

SENTINEL 자동 수집 · 증적 관리

자원으로부터 점검 데이터를 자동 수집

  • Web·WAS·DB·Server 자동 데이터 수집
  • 점검 기준에 따른 상태 자동 판별
  • 원천 증적 타임스탬프 자동 보관
  • 예약·즉시 실행 유연한 스케줄링

MANAGER 통합 관리 · 대시보드
